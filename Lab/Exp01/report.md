# Experiment 1: Create a Web Page with All Possible Elements of HTML5

## Aim

To create a web page using HTML5 and demonstrate different HTML5 elements including semantic elements, text formatting, lists, tables, forms, multimedia, and interactive elements.

## Objective

After completing this experiment, we will be able to:

1. Create a well-structured HTML5 web page.
2. Use semantic HTML5 elements.
3. Create different types of lists and tables.
4. Create forms using different HTML5 input types.
5. Add images, audio, and video to a web page.
6. Implement interactive HTML5 elements.
7. Understand the basic structure of an HTML5 document.

## Technologies Used

## Viva Preparation

### 1. What is HTML5?

HTML5 is the standard markup language used to structure and create web pages.

### 2. What are semantic elements?

Semantic elements clearly describe their meaning, such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.

### 3. What is the purpose of `<!DOCTYPE html>`?

It tells the browser that the document uses HTML5 and should be rendered in standards mode.

### 4. What is the difference between `<ul>` and `<ol>`?

`<ul>` creates an unordered list, while `<ol>` creates an ordered list.

### 5. What is the purpose of the `<form>` element?

The `<form>` element is used to collect and submit user information.

### 6. What is the purpose of the `<audio>` and `<video>` elements?

They are used to embed audio and video content directly into a webpage.

### 7. What is the `<dialog>` element?

The `<dialog>` element is used to create a dialog box or modal component.

### 8. What is the purpose of the `<datalist>` element?

It provides predefined suggestions for an input field and supports autocomplete functionality.
